REALMFORGE V11.6.1 — PRODUCTION FOUNDATION AUDIT ADDENDUM

ROOT CAUSE OF V11.6.0 REGRESSION
================================
V11.6.0 concatenated all 93 active historical patches into one JavaScript execution unit.
That changed an important runtime property of the previous build. With 93 separate classic
<script> files, an uncaught exception in one historical patch did not prevent later patch
files from executing. With direct concatenation, the same exception terminated the entire
combined runtime, leaving the game at an older effective patch level.

The player's observed symptoms matched this exactly: the custom V10.38 navigation shell
was visible while later navigation, Pack, loadout and Wayfinder upgrades were absent.

CORRECTION
==========
V11.6.1 keeps the one-file runtime download, but each embedded historical patch is executed
as its own classic script element in the exact V11.5.3 load order. This restores:
- per-patch exception isolation
- classic global-script semantics
- exact patch ordering
while retaining a five-file active runtime surface in index.html.
