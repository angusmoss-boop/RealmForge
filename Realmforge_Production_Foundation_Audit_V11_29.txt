AUDIT TARGET
Stop treating residual legacy size as the primary metric. Classify every remaining historical execution boundary by purpose, prove whether any source is genuinely obsolete, and establish a validated authoring surface so future V12 content does not recreate patch-era coupling.

COMPATIBILITY FINDING
The V11.28 compatibility runtime contains 93 historical timeline entries and is 64,639 bytes. After inspection, no remaining entry can be deleted with sufficient semantic/save proof in V11.29.

Classification:
- 80 canonical chronology bridges: implementation is already canonical; the boundary preserves historical ordering.
- 12 save/migration bridges: implementation/data ownership is canonical, but migration invocation or historical activation order still matters.
- 1 mixed historical runtime stage: V3 retains the combined Delve + Prospector finishActivity wrapper.
- 0 retireable obsolete stages.

The detailed patch-by-patch result is written to COMPATIBILITY_CLASSIFICATION_V11_29.txt and exposed at runtime through core.compatibilityClassification.

V11.29 deliberately leaves compatibility at 64,639 bytes. Deleting chronology or migration bridges solely to report a smaller number would make the architecture less trustworthy, not more production-ready.

AUTHORING FINDING
RF.Catalog and RF.Config were already the correct canonical data boundaries, but their author-facing API and validation coverage were too small for a large V12 content expansion.

V11.29 adds data.authoring / RF.Authoring with:
- validated single-record registration;
- validated multi-record registration;
- content-pack registration;
- static Config definition helper;
- structured Catalog validation;
- structured Config/world validation;
- full report/assert gate.

The current game validates with 0 authoring errors. Current headline catalog counts include 170 items, 88 enemies and 21 locations, with 19 canonical Config definitions.

VALIDATION COVERAGE
V11.29 catches broken IDs/references for enemy drops, recipe inputs/outputs/skills, location neighbours, NPC locations, perk prerequisites, quest chains/objectives, shop stock, event locations, markets, ecosystems, service locations, burglary loot, equipment stat configuration, exploration pools, dungeon bosses/rewards/materials and V11.4 dungeon registrations.
